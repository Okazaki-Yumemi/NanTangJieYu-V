## 150 用户 FX 短时回归

```sh
node scripts/benchmark-backend.js --users 150 --seconds 15 --writes fx
```

Windows 开发机本地运行，使用临时目录与独立 Node 进程。每个账户预置 12 笔持仓和 30 笔结算，行情含 360 根基础蜡烛；150 笔同时平仓后运行 15 秒混合读写。此场景固定报价，以测量存储和完整响应开销；实时新闻、跳空强平与过期报价由领域及 HTTP 测试覆盖。它不等同于低配云机长时负载测试，也不是先前的全站混合场景。
