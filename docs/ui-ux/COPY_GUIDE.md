# Copy Guide（文案规范）

## 语气分层

- 玩家 UI：短、明确、带一点世界观味，不玩到看不懂。
- 剧情/异变（seeds）：轻小说式但克制；句子短；不堆形容词；不滥用破折号/引号。
- 角色互动：灵梦=直接嫌麻烦务实（提赛钱）；魔理沙=自信豪爽火力优先（借东西玩笑）；琪露诺=自信过头笨得可爱（不必每句「最强」）；文=新闻+速度+兴奋；早苗=常识人反差，不堆网络梗。
- 管理端：精确、无歧义、少玩梗、写明后果（例：将「思源湖」标记为已解决，并解锁后续区域与奖品。此操作写入管理日志。确定继续？）。

## 术语表（唯一用词）

- 调查（玩家核心动作）；互动（按钮/系统层）；贡献（个人/阵营，不加"积分/点数"）
- 异变、异变值（区域进度量）；「异变解决」= cleared（UI 统一中文，禁止 CLEAR/cleared 出现在面向用户的界面）
- 区域解锁 / 未解锁；能量（⚡ 只是图形符号，文案写「能量」）；冷却
- 抽奖权重；终盘奖池；奖品解锁（「已进入奖池 / 未解锁」）；注册码；阵营（灵梦队/魔理沙队）；队伍成员数
- 服务端技术词（client_request_id 等）绝不暴露给玩家

## 状态文案

- locked：未解锁 + 提示「需要先解决「XX」的异变。」
- available：可调查；investigating：调查中；cleared：已解决；closed：临时关闭（提示留意现场广播）
- 活动态：未开始 / 进行中 / 已暂停 / 已结束
- 空态要有人味：「还没有人在这里留下足迹。」「等待第一份调查报告……」

## 标点与格式

- 中文界面以全角标点为主；书名号用于区域名「思源湖」；数值千分位（formatNumber）。
- 时长：`X 秒` / `X 分钟` / `X 时 X 分`（≥1 分钟不带零秒）。
- 收益展示：`贡献 +N`、`异变 -N`；按钮预期：`能量 N · 贡献 A~B · 异变 -C~D`。
- 禁止：中英夹杂技术词（强制 CLEAR→强制解决）；「操作成功/请求失败」这类无上下文提示（必须说明发生了什么/下一步）；同一概念换词。

## 已确认设定

- 六区域推进：思源门→思源湖→凯旋门→电草→涵泽湖→行政楼（电草=电院大草坪简称）。
- 幕后：摩多罗隐岐奈，后户之国「后门」；终盘行政楼 CLEAR 后她退场留「风景不错，下次再来」。
- 标题：东方南堂界遇 V / 被隐匿的交通大学 / Hidden SJTU in Four Seasons。
